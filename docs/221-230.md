# GomsBook AI Interview 221\~230 상세판

> 주제: RAG/LLM · Agent

## 221. RAG 실패의 주요 원인은?

### 답변

Retrieval miss/noise, 잘못된 Chunking, Context 부족, 생성 단계의 Context
무시나 Hallucination 등입니다.

### 상세 설명

RAG에서는 Retrieval과 Generation을 분리해서 진단해야 합니다. 관련 근거가
Top-K에 없으면 Retrieval Failure이고, 근거가 있는데도 답변이 틀리거나
근거를 벗어나면 Generation Failure입니다. 따라서 단일 최종
정답률만으로는 개선 원인을 알기 어렵습니다.

### 면접 핵심

> Retrieval miss/noise, 잘못된 Chunking, Context 부족, 생성 단계의
> Context 무시나 Hallucination 등입니다.

### GomsBook 프로젝트 연결

GomsBook의 EPUB/XHTML RAG에서는 Query Embedding → project-scoped
Retrieval → Top-K/Reranking → Context Expansion → LLM Answer 흐름으로
연결할 수 있으며, Retrieval metric과 Generation metric을 따로 측정해야
합니다.

### 꼬리질문

**Q. 성능이 낮다면 무엇부터 확인하나요?**

먼저 정답 근거가 Top-K에 들어오는지 확인합니다. 없다면 Retrieval
문제이므로 Query, Chunking, Embedding, Top-K, Threshold, Metadata를
점검하고, 근거가 있는데 답이 틀리면 Prompt와 Generation 단계로 범위를
좁힙니다.

## 226. Attention의 계산 복잡도는?

### 답변

표준 Self-Attention의 score 계산은 sequence length n에 대해 대략 O(n²d),
attention matrix memory는 O(n²)입니다.

### 상세 설명

Attention은 Query와 Key의 관련성을 점수화하고 Softmax로 정규화한 뒤
Value를 가중합합니다. √d_k로 나누는 이유는 차원이 커질수록 Dot Product
분산이 커져 Softmax가 과도하게 포화되는 것을 완화하기 위해서입니다.

### 핵심 수식

$$
\text{Attention score compute}\approx O(n^2d),\qquad \text{attention matrix memory}=O(n^2)
$$

### 면접 핵심

> 표준 Self-Attention의 score 계산은 sequence length n에 대해 대략
> O(n²d), attention matrix memory는 O(n²)입니다.

### GomsBook 프로젝트 연결

GomsBook의 EPUB/XHTML RAG에서는 Query Embedding → project-scoped
Retrieval → Top-K/Reranking → Context Expansion → LLM Answer 흐름으로
연결할 수 있으며, Retrieval metric과 Generation metric을 따로 측정해야
합니다.

### 꼬리질문

**Q. 이 수식이 학습에서 왜 중요한가요?**

수식은 모델의 출력이 어떻게 점수·확률·Loss로 연결되고 그 Loss가 다시
Gradient를 통해 Parameter update로 이어지는지를 설명합니다. 각 항의
의미와 차원을 설명할 수 있어야 합니다.

## 229. LoRA란?

Parameter-Efficient Fine-Tuning 방법입니다.

### 상세 설명

기존 Weight를 고정하고 저랭크 행렬 BA로 표현한 변화량 ΔW를 학습하는
