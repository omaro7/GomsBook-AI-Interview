## 005. Transformer란 무엇인가요?

### 답변

Attention을 중심으로 시퀀스를 처리하여 토큰 관계를 직접 계산하고 병렬 학습에 유리한 신경망 구조입니다.

### 상세 설명

Transformer 관점에서는 각 Token의 표현을 문맥에 맞게 갱신하는 과정과 학습·추론 비용을 함께 이해해야 합니다. 수식의 차원과 데이터 흐름을 설명할 수 있으면 면접 꼬리질문에 대응하기 좋습니다.

## 008. Embedding이란?

### 답변

### 상세 설명

RAG에서는 검색 단계와 생성 단계를 분리해서 보는 것이 중요합니다. 검색 품질이 낮으면 LLM이 좋은 생성 능력을 가져도 근거 기반 답변의 안정성이 떨어질 수 있습니다.

## 010. AI Agent란 무엇인가요?

### 답변

목표를 이해하고 LLM 판단을 바탕으로 Tool과 외부 시스템을 선택·실행하는 시스템입니다.

### 상세 설명

Agent 시스템에서는 LLM의 판단과 실제 실행을 분리해야 합니다. LLM은 다음 행동이나 Tool을 선택할 수 있지만 실제 실행, 권한 검증, timeout, retry, 승인 같은 제어는 Runtime 계층에서 결정론적으로 관리하는 것이 안전합니다.

### 면접 핵심

> 목표를 이해하고 LLM 판단을 바탕으로 Tool과 외부 시스템을 선택·실행하는 시스템입니다.

### 꼬리질문

**Q. 이 기능을 LLM에게 맡기지 않고 코드로 강제해야 하는 부분은 무엇입니까?**

답변할 때는 정의를 반복하기보다 선택 기준, Trade-off, 실패 원인, 평가 방법까지 연결해 설명합니다.
