> 주제: 심화 면접 · EPUB RAG · Agent 평가

## 111. 왜 MCP를 직접 구현했나요?

### 답변

프로토콜 내부 구조와 Agent-Tool 분리를 이해하기 위한 엔지니어링 기반
작업입니다.

### 상세 설명

Agentic 시스템의 핵심은 '모델의 판단'과 '실제 권한을 가진 실행'을
분리하는 것입니다. Tool allowlist, Argument/Schema 검증, 최대 반복 횟수,
Timeout, 승인, Audit Log 같은 제어는 LLM의 자연어 판단에만 의존하지 않고
Runtime에서 강제하는 것이 중요합니다.

### 면접 핵심

> 프로토콜 내부 구조와 Agent-Tool 분리를 이해하기 위한 엔지니어링 기반
> 작업입니다.

### GomsBook 프로젝트 연결

GomsBook AI Agent에서는 LLM 판단과 Tool 실행을 분리하고, EPUB 변경
작업은 승인 상태를 거쳐 적용하도록 설계할 수 있습니다. 조회 Tool은
자동화하고 수정·삭제·생성처럼 부작용이 큰 Tool에는 HITL과 Validation을
적용하는 구조가 적합합니다.

### 꼬리질문

**Q. LLM에게 맡기지 말아야 할 부분은 무엇인가요?**

권한 검사, 허용 경로, Schema 검증, 최대 반복 횟수, Timeout, 승인 필요
여부 같은 안전 정책은 Application/Runtime이 결정론적으로 강제해야
합니다.
