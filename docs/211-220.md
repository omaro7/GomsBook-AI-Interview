## 211. Vector Database란?

### 답변

Embedding Vector와 Metadata를 저장하고 유사도 검색 및 ANN 인덱스를
제공하는 데이터 시스템입니다.

### 상세 설명

RAG에서는 Retrieval과 Generation을 분리해서 진단해야 합니다. 관련 근거가
Top-K에 없으면 Retrieval Failure이고, 근거가 있는데도 답변이 틀리거나
근거를 벗어나면 Generation Failure입니다. 따라서 단일 최종
정답률만으로는 개선 원인을 알기 어렵습니다.

### 면접 핵심

> Embedding Vector와 Metadata를 저장하고 유사도 검색 및 ANN 인덱스를
> 제공하는 데이터 시스템입니다.

### GomsBook 프로젝트 연결

GomsBook의 EPUB/XHTML RAG에서는 Query Embedding → project-scoped
Retrieval → Top-K/Reranking → Context Expansion → LLM Answer 흐름으로
연결할 수 있으며, Retrieval metric과 Generation metric을 따로 측정해야
합니다.

## 219. RRF란?

### 답변

Reciprocal Rank Fusion으로 여러 검색기의 raw score 대신 순위를 이용해
결과를 결합하는 방법입니다.

### 상세 설명

RAG에서는 Retrieval과 Generation을 분리해서 진단해야 합니다. 관련 근거가
Top-K에 없으면 Retrieval Failure이고, 근거가 있는데도 답변이 틀리거나
근거를 벗어나면 Generation Failure입니다. 따라서 단일 최종
정답률만으로는 개선 원인을 알기 어렵습니다.

### 핵심 수식

$$
\mathrm{RRF}(d)=\sum_r\frac{1}{k+\mathrm{rank}_r(d)}
$$

## 220. Ablation Study란?

### 답변

시스템 구성 요소를 추가·제거하며 각 요소가 성능에 미치는 기여를 분리해
분석하는 실험입니다.

### 상세 설명

연구에서는 개선된 점수보다 그 점수의 원인을 설명할 수 있어야 합니다.
Baseline과 Control Variable을 고정하고 Independent Variable만 바꾸며,
반복 측정·효과 크기·오류 유형을 함께 분석해야 결과의 신뢰성이
높아집니다.

### 면접 핵심

> 시스템 구성 요소를 추가·제거하며 각 요소가 성능에 미치는 기여를 분리해
> 분석하는 실험입니다.

### GomsBook 프로젝트 연결

GomsBook RAG 평가에서는 Golden Dataset을 기준으로 실제 Retrieval과
Answer를 실행하고 Context Precision/Recall, Faithfulness, Answer
Relevancy, NO_ANSWER 등을 분리 평가할 수 있습니다. 연구 단계에서는
개발용 평가셋과 Held-out Test를 분리하는 것이 중요합니다.

### 꼬리질문

**Q. 좋은 실험인지 어떻게 판단하나요?**

비교할 Baseline이 있고, 독립변수 외 조건을 통제하며, 평가 Dataset과
Metric이 사전에 정의되고, 반복 가능한 설정과 Error Analysis가 있어야
합니다.
