## 281. Gradient Descent란 무엇인가요?

### 답변

Loss의 Gradient 반대 방향으로 Parameter를 반복 업데이트해 Loss를
최소화하는 최적화 방법입니다.

### 상세 설명

Gradient는 Loss가 가장 빠르게 증가하는 방향이므로 그 반대 방향으로
이동합니다. 학습률 η가 너무 크면 최소점을 지나치거나 발산하고, 너무
작으면 수렴이 느립니다.

### 핵심 수식

$$
\theta_{t+1}=\theta_t-\eta\nabla L(\theta_t)
$$

### 면접 핵심

> Loss의 Gradient 반대 방향으로 Parameter를 반복 업데이트해 Loss를
> 최소화하는 최적화 방법입니다.

### 꼬리질문

**Q. 이 수식이 학습에서 왜 중요한가요?**

수식은 모델의 출력이 어떻게 점수·확률·Loss로 연결되고 그 Loss가 다시
Gradient를 통해 Parameter update로 이어지는지를 설명합니다. 각 항의
의미와 차원을 설명할 수 있어야 합니다.

## 283. Momentum이란 무엇인가요?

### 답변

과거 Gradient 방향을 누적해 진동을 줄이고 일관된 방향의 업데이트를
가속하는 최적화 기법입니다.

### 상세 설명

Deep Learning 최적화는 Gradient의 방향뿐 아니라 크기와 안정성이
중요합니다. Initialization, Normalization, Residual Connection,
Optimizer, Learning Rate Schedule, Gradient Clipping이 서로 보완적으로
작동합니다.

### 핵심 수식

$$
v_t=\beta v_{t-1}+(1-\beta)g_t,\qquad \theta_{t+1}=\theta_t-\eta v_t
$$

### 면접 핵심

> 과거 Gradient 방향을 누적해 진동을 줄이고 일관된 방향의 업데이트를
> 가속하는 최적화 기법입니다.

### 꼬리질문

**Q. 이 개념의 한계는 무엇인가요?**

어떤 기법도 모든 데이터와 문제에서 항상 최선은 아닙니다. 적용 가정이
깨지는 상황, 계산 비용, 데이터 요구량, 오류 유형을 확인하고 Baseline과
비교해 선택해야 합니다.

## 284. Adam Optimizer란 무엇인가요?

### 답변

Gradient의 1차 모멘트와 제곱 Gradient의 2차 raw moment를 추적해
Parameter별 update scale을 적응적으로 조절합니다.

### 상세 설명

Deep Learning 최적화는 Gradient의 방향뿐 아니라 크기와 안정성이
중요합니다. Initialization, Normalization, Residual Connection,
Optimizer, Learning Rate Schedule, Gradient Clipping이 서로 보완적으로
작동합니다.

### 핵심 수식

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,\qquad v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2
$$

### 면접 핵심

> Gradient의 1차 모멘트와 제곱 Gradient의 2차 raw moment를 추적해
> Parameter별 update scale을 적응적으로 조절합니다.

### 꼬리질문

**Q. Adam과 AdamW는 무엇이 다른가요?**

AdamW는 Weight Decay를 Gradient 기반 update와 분리(decoupled)해
적용합니다. Adaptive optimizer에서 L2 penalty와 Weight Decay가 항상 같은
효과를 내지 않기 때문에 이 구분이 중요합니다.

## 288. Xavier Initialization이란?

### 답변

fan-in과 fan-out을 고려해 Layer를 통과하는 Activation/Gradient 분산을
안정적으로 유지하려는 Weight 초기화 방법입니다.

### 상세 설명

Deep Learning 최적화는 Gradient의 방향뿐 아니라 크기와 안정성이
중요합니다. Initialization, Normalization, Residual Connection,
Optimizer, Learning Rate Schedule, Gradient Clipping이 서로 보완적으로
작동합니다.

### 핵심 수식

$$
\operatorname{Var}(W)\approx\frac{2}{fan_{in}+fan_{out}}
$$

### 면접 핵심

> fan-in과 fan-out을 고려해 Layer를 통과하는 Activation/Gradient 분산을
> 안정적으로 유지하려는 Weight 초기화 방법입니다.
