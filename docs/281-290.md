## 281. Gradient Descent란 무엇인가요?

### 답변

Loss의 Gradient 반대 방향으로 Parameter를 반복 업데이트해 Loss를 최소화하는 최적화 방법입니다.

### 상세 설명

딥러닝 학습에서는 Loss의 Gradient를 안정적으로 전달하고 적절한 크기로 Parameter를 업데이트하는 것이 핵심입니다. Optimizer, Learning Rate, Initialization, Normalization은 이 안정성과 직접 연결됩니다.

### 핵심 공식

`θₜ₊₁ = θₜ - η∇L(θₜ)`

### 면접 핵심

> Loss의 Gradient 반대 방향으로 Parameter를 반복 업데이트해 Loss를 최소화하는 최적화 방법입니다.

## 290. BatchNorm과 LayerNorm의 차이는?

### 답변

BatchNorm은 batch 통계에 의존하고 LayerNorm은 각 sample/token의 feature 차원을 정규화해 Transformer에 적합합니다.

### 상세 설명

Transformer 관점에서는 각 Token의 표현을 문맥에 맞게 갱신하는 과정과 학습·추론 비용을 함께 이해해야 합니다. 수식의 차원과 데이터 흐름을 설명할 수 있으면 면접 꼬리질문에 대응하기 좋습니다.

### 면접 핵심

> BatchNorm은 batch 통계에 의존하고 LayerNorm은 각 sample/token의 feature 차원을 정규화해 Transformer에 적합합니다.
