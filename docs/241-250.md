> 주제: Agent Workflow · HITL · 평가

## 241. AI Agent의 Workflow는 어떻게 구성되나요?

### 답변

Goal→Reason/Plan→Action→Observation→Next Action→Final Answer의 반복 실행 구조로 볼 수 있습니다.

### 상세 설명

Agent 시스템에서는 LLM의 판단과 실제 실행을 분리해야 합니다. LLM은 다음 행동이나 Tool을 선택할 수 있지만 실제 실행, 권한 검증, timeout, retry, 승인 같은 제어는 Runtime 계층에서 결정론적으로 관리하는 것이 안전합니다.

### 면접 핵심

> Goal→Reason/Plan→Action→Observation→Next Action→Final Answer의 반복 실행 구조로 볼 수 있습니다.

### GomsBook 프로젝트 연결

GomsBook AI Agent에서는 Agent Runtime과 Tool 실행 계층을 분리하고, EPUB 변경처럼 부작용이 있는 작업은 승인(HITL)과 검증을 거쳐 실행하는 구조로 연결할 수 있습니다.

### 꼬리질문

**Q. 이 기능을 LLM에게 맡기지 않고 코드로 강제해야 하는 부분은 무엇입니까?**

답변할 때는 정의를 반복하기보다 선택 기준, Trade-off, 실패 원인, 평가 방법까지 연결해 설명합니다.
