## 191. Faithfulness란?

### 답변

생성 답변의 주장들이 제공된 Context에 의해 뒷받침되는 정도입니다.

### 상세 설명

RAG에서는 Retrieval과 Generation을 분리해서 진단해야 합니다. 관련 근거가
Top-K에 없으면 Retrieval Failure이고, 근거가 있는데도 답변이 틀리거나
근거를 벗어나면 Generation Failure입니다. 따라서 단일 최종
정답률만으로는 개선 원인을 알기 어렵습니다.

### 면접 핵심

> 생성 답변의 주장들이 제공된 Context에 의해 뒷받침되는 정도입니다.

Answer를 실행하고 Context Precision/Recall, Faithfulness, Answer
Relevancy, NO_ANSWER 등을 분리 평가할 수 있습니다. 연구 단계에서는
개발용 평가셋과 Held-out Test를 분리하는 것이 중요합니다.
