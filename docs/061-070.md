# GomsBook AI Interview 061\~070 상세판

> 주제: RAG · Retrieval · Agentic RAG

## 061. Embedding이란?

### 답변

비정형 데이터를 의미적 Vector로 표현하는 방법입니다.

### 상세 설명

Embedding의 핵심은 의미적으로 비슷한 입력이 Vector 공간에서도 가깝도록
표현하는 것입니다. RAG에서는 Document와 Query를 같은 Embedding 공간으로
보내 Cosine Similarity나 Dot Product로 후보를 찾습니다.

### 면접 핵심

> 비정형 데이터를 의미적 Vector로 표현하는 방법입니다.

### GomsBook 프로젝트 연결

GomsBook의 EPUB/XHTML RAG에서는 Query Embedding → project-scoped
Retrieval → Top-K/Reranking → Context Expansion → LLM Answer 흐름으로
연결할 수 있으며, Retrieval metric과 Generation metric을 따로 측정해야
합니다.

### 꼬리질문

**Q. 성능이 낮다면 무엇부터 확인하나요?**

먼저 정답 근거가 Top-K에 들어오는지 확인합니다. 없다면 Retrieval
문제이므로 Query, Chunking, Embedding, Top-K, Threshold, Metadata를
점검하고, 근거가 있는데 답이 틀리면 Prompt와 Generation 단계로 범위를
좁힙니다.
