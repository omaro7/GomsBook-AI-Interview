# GomsBook-AI-Interview

AI 대학원 및 AI 개발자 면접 준비용 300문항 Q&A입니다.

- **001~190:** 기존 학습 문서 원문을 유지해 분할
- **191~300:** 기존 학습 흐름과 GomsBook AI 프로젝트 방향에 맞춰 추가 구성
- **관리 단위:** 10문항 × 30개 Markdown
- **관리 원칙:** 문제 번호는 고정하고 답변 내용만 개선
