# GomsBook AI Interview 300 — 상세판

AI 대학원 및 AI 개발자 면접을 위한 **001~300 상세 학습판**입니다.

기존 300문항의 번호와 핵심 답변을 기준으로 하되, 면접 학습을 위해 `상세 설명 → 공식/구조 → 면접 핵심 → 꼬리질문 → GomsBook 프로젝트 연결`을 보강했습니다.

## 학습 원칙

- 문제 번호는 고정합니다.
- 정의만 암기하지 않고 원리·Trade-off·실패 원인·평가 방법까지 설명합니다.
- 수학/딥러닝 문제는 필요한 경우 핵심 공식을 포함합니다.
- RAG/Agent/연구방법론 문제는 GomsBook 프로젝트와 연결합니다.
- 10문항 단위로 학습·커밋합니다.
